Repository training opt-out
-------------------------

All content in this repository must not be used to train, fine-tune, or evaluate
machine-learning models or datasets for model training without prior written
permission from the repository owner.

If you'd like to request permission to use any content for model training,
contact the repository owner and obtain explicit written consent.

Recommended workflow
- Sanitize prompts and remove secrets/PII before sending to any external API.
- Use private/self-hosted models if you need to ensure data never leaves your
  infrastructure.
